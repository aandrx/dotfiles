# Hyprland example

`hyprland.conf` is the entry point: it sources `colors.conf`, sets the monitor
and a few variables, then sources one file per concern.

- `configs/looknfeel.conf`: gaps, borders, blur, animations
- `configs/input.conf`: keyboard, mouse, touchpad
- `configs/windowrules.conf`: window and layer rules
- `configs/keybinds.conf`: binds, using `$mainMod` from `hyprland.conf`

`colors.conf` is a sample palette; the author's copy is generated by matugen.
Nothing else ships: no helper scripts, no backup configs, no disabled fragments.

Check a change before reloading:

```sh
Hyprland -c hyprland.conf --verify-config
```
