# Waybar for niri: example

This is a split waybar setup. The bar reads `config.jsonc` and `style.css`,
which include `profiles/status/`; that is the default profile. `profiles/bottom/`
is a second complete profile for a bottom bar. Each profile owns its config,
module list and styles; shared colours and module CSS stay at the top level and
are reached through relative symlinks. `colors.css` is a sample palette; the
author's copy is generated by matugen.

`profiles/README.md` explains what a profile is and how to add your own. The
public example does not include the author's `waybar-profile` switcher or the
`current` symlink it manages; launch a profile directly to try it.

Check a profile before launching it:

```sh
waybar -c profiles/status/config.jsonc -s profiles/status/style.css
waybar -c profiles/bottom/config.jsonc -s profiles/bottom/style.css
```
