# Waybar for niri: example

This is a split waybar setup. The bar reads `config.jsonc` and `style.css`,
which only include `profiles/status/`, so the profile is the single copy of the
80-line config and its styles. `colors.css` is a sample palette; the author's
copy is generated by matugen.

`profiles/README.md` explains what a profile is, how switching works, and how to
add your own. A second profile in the author's setup is the same bar at the
bottom edge.

Check a profile before launching it:

```sh
waybar -c profiles/status/config.jsonc -s profiles/status/style.css
```
