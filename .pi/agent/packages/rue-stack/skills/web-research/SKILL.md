# Web research

1. Define the claim that requires current external evidence.
2. Search for a primary source first, then one independent source only when corroboration matters.
3. Fetch the specific pages needed rather than broad result sets.
4. Cite every material current claim with its URL and distinguish observation from inference.
5. If no web search or fetch tool is available, stop immediately and report that limitation. Do not load rue-mode, browser-tools, or frontend-design as substitutes.
6. Stop when the claim is verified or when two search approaches fail; report the gap instead of looping providers.
7. Never submit secrets, private URLs, cookies, or credential-bearing links to a search or extraction service.
