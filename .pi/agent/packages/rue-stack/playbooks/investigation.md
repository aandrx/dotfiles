# Investigation

1. Restate the exact question and identify what evidence would answer it.
2. Inspect the smallest set of authoritative code, tests, history, documentation, or runtime evidence.
3. Trace the relevant data and control flow end to end without changing files.
4. Test material hypotheses where the available surface permits it.
5. Separate observed facts, supported inference, and unresolved uncertainty.
6. Answer the question with precise source references and verification limits.
