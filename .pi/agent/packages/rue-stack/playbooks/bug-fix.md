# Bug fix

1. Reproduce the reported failure through the closest user-facing or runtime surface and record the failing evidence.
2. Trace the root cause before editing code.
3. Add the cheapest focused regression test that fails for the reproduced defect when practical.
4. Make the smallest robust correction at the cause, not the symptom.
5. Run the focused test and the relevant broader checks.
6. Verify through the original reproduction surface and report remaining limits.
